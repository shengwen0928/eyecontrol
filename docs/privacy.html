凝視 — 隱私權政策

生效日期：2026 年 11 月 22 日｜開發者：Zhu（個人開發者）

凝視（下稱「本應用程式」）是一款無障礙輔助工具， 讓使用者以視線移動游標、以凝視停留或眨眼觸發點擊，藉此操作 Android 裝置。 我們深知視覺資料的敏感性，本政策說明本應用程式如何處理您的資訊。

一、我們「不」收集的資料

本應用程式不收集、不儲存、不上傳任何個人資料，包括：

  • 相機影像或影片——前鏡頭畫面僅在裝置端記憶體中即時分析，用完即棄，永不寫入儲存空間、永不離開您的裝置
  • 臉部特徵、虹膜或任何生物特徵原始資料
  • 身分資訊、聯絡資訊、位置資訊、使用行為分析

唯一的例外是「遠端監控」（暫時除錯功能，預設關閉，僅 GitHub 側載版提供）： 您主動在設定中開啟後，App 會把游標診斷數字（視線落點座標、臉部角度與距離的數值、 靈敏度設定，不含任何影像）上傳到開發者的監控服務，供開發者分析游標偏移問題。 紀錄以時間戳記檔名存放（不含身分資訊），本機只保留最近 3 份；關閉開關即停止上傳。 此功能與伺服器端紀錄將在除錯完成後一併移除。

本應用程式不包含任何第三方追蹤或廣告 SDK。網路連線依發行通路而不同， 兩者皆不傳送任何個人資料：

  • Play 商店版：平時不連接網際網路；更新一律透過 Google Play 商店。
  • GitHub 側載版：平時唯一的網路連線是「更新檢查」——App 啟動時向 api.github.com 查詢最新 release 版本，只讀取公開的版本資訊。 另外只有在您主動開啟「遠端監控」時，才會上傳游標診斷數字（見上一段）， 預設關閉。

二、儲存在您裝置上的資料

視線校正完成後，僅有校正模型的數學權重數值（嶺回歸係數，不含任何影像或 生物特徵原始資料）以 Android 私有儲存模式（MODE_PRIVATE）存於裝置本機， 供下次使用時還原校正結果。解除安裝本應用程式即完全刪除。

三、權限用途說明

  • 相機（CAMERA）：以前鏡頭即時偵測虹膜位置，推算視線落點。影像僅於裝置端即時處理。
  • 無障礙服務（AccessibilityService）：本應用程式使用 Android 無障礙 API 在畫面上顯示游標覆蓋層，並在您凝視停留或眨眼時，代替手指執行點擊、捲動等手勢。 本服務不讀取、不記錄畫面內容或您在其他應用程式中的任何資訊， 僅用於注入您主動觸發的操作手勢。
  • 前台服務（FOREGROUND_SERVICE_CAMERA）：確保眼控服務在使用期間持續運作，不被系統中斷。
  • 安裝未知來源應用程式（REQUEST_INSTALL_PACKAGES，僅 GitHub 側載版）： 讓 App 內更新檢查下載新版後，能跳轉系統安裝畫面完成覆蓋安裝。Play 商店版不使用此權限。

四、關於側載安裝警告

從 GitHub 下載安裝時，Google Play 安全防護可能跳出「此應用程式可能有害」的警告。 這是因為本應用程式未經 Play 商店發行、且無障礙服務與相機權限的組合符合其啟發式判斷； 本應用程式不含惡意程式，原始碼完全公開，可自行檢視。安裝時點「瞭解詳情」→「仍要安裝」即可。 Play 商店版不受此影響。

五、兒童隱私

本應用程式不針對兒童設計，且因不收集任何資料，不涉及兒童個人資料之處理。

六、政策變更

若本政策有所變更，將於本頁面更新並調整生效日期。重大變更將於應用程式更新說明中告知。
