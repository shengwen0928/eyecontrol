## 4. 通過判定規則

1. 單項通過須同時滿足：步驟已按表執行、實際結果符合預期結果、證據已填入且可核對。任一條件不滿足，不得標示通過。
2. 失敗項須記錄重現步驟與當下狀態文字／截圖（來源：`TEST_PLAN.md` §3 通則），並列入「未解決問題」，由所有權人決定修復或接受。
3. 標示「待 D-4 決定，不可執行」「待決策」的項目（M-10、M-12），在決策完成與（M-10）實作完成之前，不得改標為通過或失敗。
4. 標示程式未做的項目（M-13、M-14），在實作完成之前，不得改標為通過；實作完成後須另排實機驗證（見 `IMPLEMENTATION_NOTES.md` §1 出入第 27 點：dispatch 部分須另排一步、另列實機驗證）。
5. 本矩陣的完成狀態不由本文件自行宣稱；完成與否以填入的證據與 `release-readiness.md` 的判定為準。
