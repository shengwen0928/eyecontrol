# EyeControl 眼控

用手機前鏡頭追蹤眼球，以視線移動游標、凝視停留或眨眼點擊，直接控制整支
Android 手機的開源無障礙原型系統。所有影像處理都在裝置端即時完成，不上傳。

> 開發狀態：研究原型，持續開發中。功能持續深化，部分新功能尚未在實機上驗證，
> 詳見[已知限制](#已知限制)。

## 研究動機

眼控輔助技術存在，但門檻很高：專用眼動儀價格昂貴、需要額外硬體與設定；
手機內建的眼控方案功能有限，而且不是每個人都用得起、用得上。對於手部動作
不便的人——例如漸凍症、腦麻、脊髓損傷患者，或暫時受傷無法用手的人——
「用眼睛操作手機」往往是維持聯繫、獲取資訊、獨立生活的關鍵，卻也是最難
取得的輔助。

這個專案想驗證一件事：**只用一支普通 Android 手機的前鏡頭，加上輕量模型，
不靠雲端、不靠專用硬體，能不能做到堪用的全系統眼控？** 如果可以，眼控輔助
的門檻就能從「買一套設備」降到「裝一個 App」。

研究的原則：

- **免費開源**：程式碼與方法全部公開，任何人都能用、能改、能接著研究。
- **裝置端運算**：影像只用於當下的視線推算，不儲存、不上傳，校正資料只有
  模型權重，不含影像或生物特徵原始資料。
- **誠實評估**：準確率怎麼量、數字有什麼限制，全部寫清楚（見
  [`docs/evaluation.md`](docs/evaluation.md)），不報未經量測的數字。

## 做出來之後要幹嘛

這個專案的終點不是「能跑就好」，而是真正有人用得上、研究走得下去：

**對使用者**：成為免費、開源、裝上一般手機就能用的眼控輔助方案；
依實際試用回饋持續改進（停留時間、眨眼靈敏度、操作模式都應該可調，
因為每個使用者的狀況不同）。

**對研究**：公開完整的方法與評估數據——特徵設計、模型、校正流程、誤差量測
方法與結果——讓後來的人可以重現、比較、改進，而不是從零重複造輪子。
實驗計畫見 [`docs/evaluation.md`](docs/evaluation.md) 的「未來要做的評估實驗」。

**路線圖**：

- 近期：多人校正設定檔、橫向支援、設定頁細節打磨（依試用回饋）；停留時間／眨眼靈敏度可調、情境校正設定檔、陀螺儀角度修正、臉部遠近修正已完成。
- 中期：跨裝置／跨光線／長時間漂移的評估實驗、特徵消融實驗、邀請真正
  需要眼控輔助的使用者試用並記錄回饋。
- 長期：Google Play 上架（applicationId 已預留 `tw.com.zhu.eyecontrol`）、
  社群維護、持續公開研究紀錄。

定位聲明：本專案是研究原型，不是醫療器材；不宣稱療效，準確率以實測為準。

## 功能

| 功能 | 說明 |
|------|------|
| 視線游標 | 全螢幕覆蓋層游標，隨視線移動，One Euro 濾波平滑去抖 |
| 凝視停留點擊 | 視線停在同一處 1 秒即點擊，停留時游標自動鎖定 |
| 眨眼點擊 | 刻意眨眼（閉眼 150–600 ms）即在閉眼前的位置點擊 |
| 模式面板 | 注視右側面板切換：點一下、點兩下、長按、滑動、暫停 |
| 邊緣手勢 | 注視螢幕邊緣：頂部返回、底部首頁、左右捲動 |
| 滑動手勢 | 滑動模式下注視起點與終點，即可拖曳／滑動 |
| 校正品質回報 | 校正完成時回報訓練集誤差、留一法交叉驗證誤差與最差校正點 |
| 可調參數 | 停留時間、冷卻、停留半徑、眨眼視窗、睜眼閾值、平滑強弱皆可在設定頁調整，儲存後即時生效 |
| 情境校正設定檔 | 坐著／躺著／平放各做一次完整 9 點校正、各存一組模型；使用前選目前情境，不混用 |
| 陀螺儀角度修正 | 旋轉向量量裝置傾斜，相對校正姿勢幾何修正預測點（預設關閉：pitch 方向可能與臉轉向補償重複計算，須實機開／關對照確認有效再開） |
| 臉部遠近修正 | 以兩眼間距比值量臉距變化，繞螢幕中心等比縮放預測偏移（設定頁可關） |
| App 內更新 | 開 App 時自動檢查最新 release，有新版一鍵下載安裝（安裝仍需使用者親自點一下） |
| 前台服務 | 無障礙服務以前台服務運行，避免被系統回收 |
| 臉遺失提示 | 偵測不到臉時游標留在原地變灰，明確告知狀態而非當機 |

## 架構與方法

```
前鏡頭 (CameraX, 1280×720)
  → MediaPipe Face Landmarker（478 臉部關鍵點，含虹膜）
  → GazeFeatureExtractor：22 維視線特徵（見下）
  → GazeModel：9 點校正訓練的嶺回歸，特徵 → 螢幕座標，頭部姿態補償共訓
  → OneEuroFilter：平滑去抖動（停留時自動加強平滑）
  → GazeAccessibilityService：覆蓋層游標 + 凝視停留／眨眼觸發 dispatchGesture
```

**22 維特徵**（`GazeFeatureExtractor`，全部以眼寬／眼距正規化，對距離變化不敏感）：

- 雙眼虹膜在眼眶座標系內的相對位置（經轉頭 roll 旋轉回正，具轉頭不變性）
- 頭部姿態代理：pitch／yaw／roll（由鼻尖與兩眼連線推算）
- 眼睛–頭部交互項與二階項（pitch²、yaw²、pitch·yaw），捕捉頭轉時的非線性響應
- 雙眼平均、雙眼差分（輻輳）、眼距及其平方、眼睛睜開程度（眨眼偵測用）

**模型**（`GazeModel`）：兩組嶺回歸權重（x、y 各一），以高斯消去法解正規方程；
頭部姿態補償係數 kx、ky 與權重一起訓練、限制在 -3.0–3.0（符號由校正資料決定，不預設方向；v0.4.1 修正：舊版強制正值會把垂直補償算反、游標被壓向中下方）。
模型存檔含格式版本號，版本不符或維度不符一律視為未校正，避免靜默誤用舊模型。

**校正**（`CalibrationActivity`）：全螢幕 3×3 九點，頭保持不動、只用眼睛看；
每個情境（坐著／躺著／平放）各做一次，各存一組模型，不混用；

**姿勢與距離融合**：臉轉向（特徵 7/8 的帶符號差值）由 kx/ky 補償項在訓練時聯合學出；裝置角度（融合陀螺儀的旋轉向量）與臉遠近（特徵 6 iod 的比值）不靠訓練學——校正時裝置不動、臉距固定，學不出係數——改以校正基準＋幾何關係修正（裝置轉動轉回、臉距等比縮放），全部只吃與校正時的變化量。注意：特徵 7/8 是相機影像座標系的量測，分不清頭動與手機動，pitch 方向的裝置修正可能與 kx/ky 補償重複計算同一轉動，因此陀螺儀修正預設關閉，須實機開／關對照確認誤差真的下降再開；roll 方向因特徵已做 roll 旋轉而不受影響。臉轉向另有方向分類（上／下／左／右與組合），變化時寫進 log。舊模型沒有基準時修正自動關閉，重新校正一次才生效；設定頁可分別開關。
每點先等 0.9 秒讓視線穩定，再收 20 幀，剔除離群值後保留 70% 併入訓練集；
眨眼／閉眼期間的樣本直接丟棄，避免污染訓練資料。

**評估**：訓練集誤差與留一校正點交叉驗證誤差分開報告，方法與限制詳見
[`docs/evaluation.md`](docs/evaluation.md)。

## 使用流程

1. 安裝 APK，開啟 App
2. 按「授予相機權限」
3. 先選使用情境（坐著／躺著／平放），再按「開始眼球校正」——手機立在面前約 30–40 cm，**頭保持不動**，只用眼睛依序看 9 個點；每個情境各做一次
4. 按「開啟無障礙服務」→ 系統設定中啟用「眼控 EyeControl」
5. 藍色游標隨視線移動：凝視同一處達到設定的停留時間（預設 1 秒）即點擊，或刻意眨眼點擊；注視右側面板切換模式；參數可在主畫面的「參數設定」調整

更新：開 App 時會自動檢查 GitHub 最新 release，有新版就跳提示，點「下載更新」即可；第一次需在系統設定允許本 App「安裝未知來源應用程式」一次，安裝當下仍需親自點一下確認（Android 對側載 App 的限制，無法完全靜默更新）。

## 建置

```
java -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

需求：JDK 17、Android SDK (API 36)。模型檔 `app/src/main/assets/face_landmarker.task`
來自 https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task

## 已知限制（原型階段）

- 精度約數十像素級，適合點大按鈕；頭部大幅移動後需重新校正
- 螢幕方向固定直向（校正座標系綁定校正當下的方向）
- 光線不足時虹膜偵測品質下降；戴眼鏡反光的影響尚未系統量測
- 校正品質回報與模型版本欄位等新功能尚未在實機上驗證
- 評估數字來自校正當下的同環境量測，換環境後誤差會變大，詳見
  [`docs/evaluation.md`](docs/evaluation.md)

## 隱私

所有影像處理皆在裝置端即時完成：前鏡頭影像僅用於當下的視線推算，**不儲存、不上傳**；
校正資料只有嶺回歸的權重數值（不含任何影像或生物特徵原始資料），以 `MODE_PRIVATE`
存於本機 SharedPreferences。唯一會連網的功能是「更新檢查」：App 啟動時向
`api.github.com` 查詢最新 release 版本，不傳送任何個人資料；除此之外不連網，
不含任何第三方追蹤。
完整隱私說明見 `docs/privacy.html`。
